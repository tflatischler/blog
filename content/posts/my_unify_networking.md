# My UniFi Networking Setup

I recently stumbled across some old UniFi networking gear in our cellar — probably left over from my dad. The haul included:

- UniFi CloudKey Gen2 Plus
- UniFi Switch 8 150W
- UniFi Security Gateway

Even though I'd never really done anything serious with networking before, I felt pretty ambitious. The plan was to set up a dedicated wired connection between my PC and a few Raspberry Pis, so I could manage them without relying on Wi-Fi.

// images missing

When I finally got around to setting up the CloudKey, I noticed it had a few issues straight away — outdated firmware being the obvious one. On startup, the UCK's display showed **"Hard Drive Disk Error"**. I figured it should still work without an HDD installed... right?

After some digging online, I found out that the older firmware versions actually *require* an HDD to function — even recovery mode wouldn't cooperate without one. So I had no choice but to track down an old hard drive on eBay.
